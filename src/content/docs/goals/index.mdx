A goal says why someone uses a method. It is not itself a method. The same device can restore a lost function for one person and enhance a usual function for another.

## Restore

Bring a lost or damaged function back toward a usual level. Therapy and rehabilitation file here. [Open the Restore hub](/goals/restore/).

## Enhance

Take a usual function past a typical level, or add a capability that was not there. [Open the Enhance hub](/goals/enhance/).

## Extend

Postpone age-related loss of function and lengthen healthspan, not merely years alive. Aging biology stays on this goal, including the hallmarks note. [Open the Extend hub](/goals/longevity/).
