The description below is from FDA's GLP-1 concerns page, which names import alert 66-80. The alert document itself was not parsed into this page, so the green list of firms is not copied.

## What the opened sources say

- FDA says it established a green-list import alert (66-80) to help stop GLP-1 active pharmaceutical ingredients with potential quality concerns from entering the U.S. supply chain.
- FDA says the alert does not apply to GLP-1 API from manufacturers that, based on an FDA inspection or other FDA evaluation, appear to comply with FDA manufacturing standards.
- FDA says the action does not stop legal importation from compliant API manufacturers and does not create new limits on legal compounding of GLP-1 drugs.
