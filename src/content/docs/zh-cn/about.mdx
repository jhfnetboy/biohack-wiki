开放、开源的 Biohacking wiki，帮助任何人和组织研究、了解 Biohacking 的各个领域，并为决策提供信息参考。专业跟进，持续更新，客观中立。

它不是诊所、药房或产品测评站。它不提供剂量、注射或植入步骤，或购买指引。

## 我们如何工作

- **全面覆盖。** 十个领域，从生物化学干预到生活方式，使用同一套来源规则。
- **决策参考。** 为任何人和组织的决策提供信息。不是医疗建议。
- **专业跟进，持续更新。** 每个页面记录审阅日期。在来源被核对之前，存根会一直标明。
- **客观中立。** 证据等级只来自被引用的研究设计。没有赞助排名。
- **开放、开源。** 内容采用 [CC BY-SA 4.0](/zh-cn/policies/license/)。代码采用 MIT。编辑链接指向[公开的 GitHub 仓库](https://github.com/jhfnetboy/biohack-wiki)。[贡献指南](/zh-cn/contributing/)说明如何添加页面。
