ไม่มีภาพถ่ายจาก Canaltech, maxon, TUI, 艾邦 หรือ `images.openai.com`

## ภาพประกอบที่สร้างด้วย AI

ทำขึ้นสำหรับ BioHack Wiki เมื่อ 20 พฤศจิกายน 2026 ไม่ใช่ภาพถ่ายผู้ป่วย อุปกรณ์จริง หรือสินค้าที่มีแบรนด์ ไฟล์อยู่ใน `src/assets/illustrations/`

| ไฟล์ | สิ่งที่แสดง |
| --- | --- |
| hero.webp | เงาคนเรืองแสง ชั้นของการวัด ชีวเคมี และประสาท |
| domain-biochemical.webp | สายคล้ายเปปไทด์เหนือเครื่องแก้ว |
| domain-neurohacking.webp | สมอง โครงข่าย และชุดสวมศีรษะ EEG ทั่วไป |
| domain-bionic.webp | มือเทียมไมโออิเล็กทริก |
| domain-cyborg.webp | ชิปฝังขนาดเล็กใต้ผิวมือ |
| domain-genetic.webp | เกลียว DNA และภาพการแก้ไขแบบนามธรรม |
| domain-longevity.webp | เซลล์รอบนาฬิกาทราย |
| domain-quantified-self.webp | แหวน นาฬิกา แผ่นแนว CGM และเส้นข้อมูล |
| domain-microbiome.webp | ชุมชนจุลินทรีย์ในลำไส้แบบภาพวาด |
| domain-lifestyle.webp | ส่วนโค้งเซอร์คาเดียน การนอน การเคลื่อนไหว และน้ำเย็น |
| scene-bci.webp | ฉากฟื้นฟู: ชุดสวมศีรษะและแขนกล |
| scene-prosthetic-hand.webp | มือเทียมถือถ้วย |
| scene-exoskeleton.webp | โครงกระดูกกลช่วยเดิน |
| scene-eskin.webp | แผ่นผิวอิเล็กทรอนิกส์บนปลายนิ้วหุ่นยนต์ |
| scene-closed-loop.webp | การรับรู้ การวิเคราะห์ การแทรกแซง และการประเมิน |
| scene-principles.webp | ตราชั่งและโล่เหนือภาพคนกับเทคโนโลยี |

คำบรรยายบนหน้าขึ้นต้นด้วย “ภาพประกอบที่สร้างด้วย AI”
