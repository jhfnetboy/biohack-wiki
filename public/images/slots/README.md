# Illustration slots

The live illustrations are WebP files in `src/assets/illustrations/`, rendered with Astro `<Image>`. Captions start with “AI-generated illustration” / “AI 生成插图”. The attribution page lists every file.

This `public/images/slots/` folder is not read by the site. Do not drop Canaltech, maxon, TUI, 艾邦, or `images.openai.com` files here.
