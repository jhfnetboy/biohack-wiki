# Page templates

Copy one of these files into `src/content/docs/` (and a Simplified Chinese twin into `src/content/docs/zh-cn/` with the same path). Templates are not published.

Every template ends with the material this wiki does not publish: doses, titration, injection or implantation technique, preparation steps, and shopping guidance.

Replace the `REPLACE` placeholders. Delete any optional frontmatter you are not ready to source. If a fact is not in a document you opened, do not invent it: set `status: stub`, `noindex: true`, and write **Stub, needs sourcing** in the body.
